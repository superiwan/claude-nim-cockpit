# Interview Transcript: Claude Code NVIDIA Account Manager

## Round 1

Question:
如果这个可视化操作端只允许你“最核心地解决一件事”，你最希望它替你从头到尾接管什么流程？

Answer:
我要新增一个 NVIDIA 账号并让某几个模型开始分流，一个NVIDIA 账号只管理一个模型。就是我希望我可以随时替换NVIDIA账号并随时选择模型，就相当于Claude code 的NVIDIA账号管理器。

## Round 2

Question:
你说“一个 NVIDIA 账号只管理一个模型”，这条规则是你要这个工具强制保证的吗？

Answer:
我希望更灵活：三个账号可以绑定同一个模型，也可以三个账号分别绑定三个不同的模型。当然这些都是可以让我选择的：一个账号已经绑定了 glm5，也可以让它绑定到 kimi-k2.5；也可以不断切换账号，比如说除了我现有的三个账号，我后续想要加新的号也可以。

## Round 3

Question:
假设这个工具明天就做出来了，你最希望首页一打开就能直接完成哪 3 个动作？

Answer:
有一个账号池子，里面可以让我添加多个账号，每个账号可以设置模型，以及显示剩余额度。

## Round 4

Question:
如果 NVIDIA 没有稳定的接口让我们自动读取真实剩余额度，你能接受哪种降级方案？

Answer:
2和3。也就是根据 LiteLLM 调用日志估算用量，显示账号是否可用、最近调用是否成功、是否疑似限流。

## Round 5

Question:
第一版你明确不想做哪些东西？

Answer:
就做最小实现就行了，其他非必要的可以不做。

## Round 6

Question:
后面进入 autopilot 实现时，哪些决策你允许我直接替你定？

Answer:
桌面应用吧，其他都由你决定，你做完后告诉我就行了。
